# 파리의 작은 차이

설치나 빌드가 필요 없는 HTML/CSS/JavaScript 틀린그림찾기 게임입니다.

## 실행

이 폴더에서 `python3 -m http.server 3000 --bind 0.0.0.0`을 실행하고 브라우저로 확인하세요. `index.html`을 직접 열어도 실행할 수 있습니다.

- 1단계, 총 10개 레벨. 각 레벨 2분, 차이 5개.
- 오답 제한: `max(1, floor(10 × 0.8^(레벨-1)))` → 10, 8, 6, 5, 4, 3, 2, 2, 1, 1회.
- 정답은 양쪽 사진에 빨간 동그라미로 표시됩니다. 이미 찾은 곳은 오답으로 계산하지 않습니다.
- 레벨마다 장식 위치와 형태가 달라집니다. 두 배경 위에 있는 장식 5개의 색 차이를 찾는 방식입니다.
- 제공된 사진 URL을 불러오며 실패하면 자체 파리 일러스트를 사용합니다. 원본 사진 서버는 클라우드 다운로드 요청에 403을 반환했습니다.
- '내 사진으로 플레이'로 로컬 사진을 선택할 수 있습니다. 사진은 서버에 업로드되지 않습니다.
- 사진을 배포할 때는 해당 사진의 사용 권한을 확인하세요. 사용 가능한 원본을 `assets/paris.jpg`에 저장하고 `game.js`의 `photoURL`을 `assets/paris.jpg`로 바꾸면 외부 서버 없이 사용할 수 있습니다.

## GitHub / Vercel

이 폴더의 전체 파일을 GitHub 저장소 최상위에 업로드하세요. Vercel에서 저장소를 Import하고 Framework Preset은 Other, 빌드 명령은 비워두고 Output Directory는 `.`으로 설정하세요. 비밀 키나 환경 변수는 필요 없습니다.

`게임만들기01.zip`을 PC 바탕화면의 `게임만들기01` 폴더에 압축 해제하면 그대로 업로드할 수 있습니다.
